# План разработки

## Реализовано в 0.2.0

- [x] Python-пакет, CLI, `start()`, автоматическое определение главного файла.
- [x] Middleware aiogram 3.x, команды, нормализованные callbacks, ошибки.
- [x] Встроенная запись без отдельного локального сервера, файлы SQLite WAL.
- [x] Сохраняемый реестр ботов и сессий, heartbeat, остановка и потеря связи.
- [x] Асинхронная запись, ограничение очереди, повторы и защита от дубликатов.
- [x] Общая аналитика и точные уникальные за диапазон.
- [x] Настольное приложение, тёмная тема, поиск, фильтры, графики и ошибки.
- [x] Русский/английский интерфейсы, настройки и подтверждение очистки.
- [x] Stdio bridge, локальный запуск и SSH-команда для одного Linux-сервера.
- [x] Реальный и офлайн-примеры aiogram, автоматические и UI-проверки на Windows.
- [x] Короткий нагрузочный прогон 100 ботов, 100 событий/с.

## Проверить на целевой инфраструктуре

- [ ] Реальное SSH-подключение с компьютера владельца к Linux-серверу.
- [ ] Linux-сборку и headless-сбор в окружениях ботов.
- [ ] Запросы и очистку на большой истории, длительный нагрузочный прогон.
- [ ] Проверку установки на другом Windows-компьютере и подпись приложения.

## Реализовано в 0.3.0

- [x] Запуск, штатная остановка и перезапуск из карточки бота.
- [x] Явный профиль: аргументы, рабочая папка, подготовка, окружение и env-файл.
- [x] Проверка PID и времени создания, защита от двойного запуска.
- [x] Отдельное подтверждение принудительного завершения процесса и его потомков.
- [x] Интеграционные проверки сложного aiogram-бота: файл, модуль, PowerShell, роутеры и FSM.
- [x] Проверка настоящих кнопок Electron: старт, перезапуск, остановка и профиль.
- [x] Windows-установщик, portable-сборка, Python wheel и подготовка релиза GitHub.

## Следующие функции

В 0.5.0 добавлены копирование существующих logging/Loguru-записей, CPU/RSS процесса
каждого бота, ограниченный автоперезапуск и мастер подключения существующего проекта.

В 0.3.1 добавлены трей с восстановлением окна и полным выходом, защита от повторного
запуска окна, обучение при первом открытии и ярлыки Windows. Проверки выполнены
на Windows; поддержка трея в целевом Linux-окружении требует отдельной проверки.

- Адаптеры Windows-служб, systemd и других внешних менеджеров процессов.
- Полный просмотр консольных логов и дополнительные фреймворки.
- Архивирование больших объёмов истории и удобное резервирование из интерфейса.
