# Установка и первый бот

Эта инструкция — для готовой программы. Скачивать исходники и собирать приложение не нужно.
Используйте обычный Python, которым уже запускается ваш бот.

## 1. Установить пакет и открыть панель

В PowerShell или терминале выполните:

```sh
python -m pip install --upgrade telegram-bot-control
tgbots
```

На Linux замените `python` на `python3`. Если бот запускаете через `py`, используйте
`py -m pip install --upgrade telegram-bot-control`.
Если имя `tgbots` не найдено, запускайте **`python -m telegram_bot_control`**.

Браузер откроется автоматически с уже выполненным локальным входом. Выбирать
Python и папку вручную не требуется: используется Python запущенной команды и
стандартная папка текущего пользователя. Оставьте терминал открытым.
`Ctrl+C` остановит панель, сохранив данные и работу ботов.

Если Python ещё не установлен, [скачайте его с python.org](https://www.python.org/downloads/).
Нужна версия 3.11 или новее. Если браузер открыть не удалось, адрес и ключ доступа
останутся в терминале: откройте этот адрес вручную и введите ключ.

## 2. Если нужно отдельное desktop-окно

Это дополнительный вариант. [Установщик Windows](https://github.com/olegoleg1111121/telegram-bot-control/releases/download/v0.8.0/Telegram-Bot-Control-0.8.0-win-x64.exe)
создаёт ярлык. Откройте его: приложение само ищет Python, даже если его нет в PATH.
Рядом с каждой найденной версией видно, установлена ли в ней библиотека.
Можно повторить поиск кнопкой **Найти Python на компьютере** или выбрать файл вручную.

Если библиотека отсутствует, окно ошибки покажет команду установки именно для
выбранного Python. Скопируйте и выполните её, затем снова нажмите **Подключиться**.
Папка статистики — не папка Python; обычно её нужно оставить пустой.
Если поля перепутаны, появится кнопка **Перенести в поле Python**.

Крестик скрывает desktop-окно в трей. Для полного выхода используйте меню трея.
Команда `tgbots desktop` также открывает установленное desktop-приложение.

## 3. Подключить существующего бота

В главном файле бота найдите создание `bot` и `dp`. Сразу после них,
перед существующим `await dp.start_polling(bot)`, добавьте:

```python
from telegram_bot_control import start

monitor = start(bot=bot, dispatcher=dp, capture_logs=True)
dp.update.outer_middleware(monitor.middleware())
```

Если ваши переменные называются иначе, подставьте их имена. Не создавайте ещё один
`Bot`, `Dispatcher` или второй polling. Сохраните существующие роутеры, `.env` и настройку логгера.
Запустите бота своей обычной командой, например:

```powershell
python main.py
```

После SDK startup бот появится в списке автоматически. Сама установка пакета
бота не добавляет. Кнопка **Подключить бота** помогает выбрать проект и сохранить
команду запуска, но подключение SDK к коду всё равно необходимо.

[Для ИИ-помощника есть готовое задание](ai-integration.ru.md), а в панели — раздел
**Подключить с ИИ** с кнопкой копирования.

## Если бот не появился

1. Проверьте, что библиотека установлена через тот Python, которым запускается бот:

   ```powershell
   python -c "import telegram_bot_control; print(telegram_bot_control.__version__)"
   ```

2. Убедитесь, что `start()` и middleware добавлены и бот успешно запущен.
3. Бот и панель должны работать от одного владельца и использовать одну папку данных.
   При обычной установке оставьте папку панели пустой и не задавайте `data_dir` в коде.
4. Если бот уже подключён и просто остановлен, его карточка остаётся в списке с историей.

Если задаёте собственную папку, укажите её и в коде, и в настройках панели:
`start(..., data_dir=r"C:\BotControl\data")`. Для браузера добавьте
`--data-dir "C:\BotControl\data"` в команду запуска панели.

## Несколько Python или уже настроенное окружение

Для бота с собственным интерпретатором устанавливайте SDK через **его** Python.
Не создавайте новое окружение и не переносите туда работающего бота.
Замените слово `python` в командах на способ, которым уже запускаете этот бот.
Например, если запуск — `py -3.12 main.py`, установка —
`py -3.12 -m pip install --upgrade telegram-bot-control`.
[Как выбирать интерпретатор для pip](https://pip.pypa.io/en/stable/user_guide/#running-pip).

Для webhook свяжите `await dp.emit_startup(bot=bot)` и `await dp.emit_shutdown(bot=bot)`
с существующим lifecycle приложения. Для штатной остановки webhook из панели передайте
в `start(shutdown=...)` callback, который корректно останавливает приложение.
[Сложные команды, подготовка и остановка](process-control.md).

Если бот на удалённом Linux-сервере, устанавливайте SDK на сервере. Окно приложения
можно открыть на своём компьютере и выбрать **SSH**. Укажите адрес, пользователя,
Python сервера и папку данных. [Как устроено SSH-подключение](transport.md).
