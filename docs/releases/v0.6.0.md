# Telegram Bot Control 0.6.0

События и аналитика: добавляйте `monitor.track_action("order.completed")` в код
бота или `@monitor.action("report.generate")` над функцией. Панель показывает
график, пользователей, ошибки, длительность и историю с точным временем.
Фильтры по боту, имени, источнику, результату и периоду. Старые callback-события совместимы.

Русский стал основным языком README, на PyPI описание на русском и английском.
Добавлен [готовый промпт для подключения с ИИ](https://github.com/olegoleg1111121/telegram-bot-control/blob/main/docs/ai-integration.ru.md)
в репозитории, панели и мастере подключения. Обычный Python и существующий venv
поддерживаются; дополнительные runtime-зависимости не добавлены.

```sh
python -m pip install --upgrade telegram-bot-control
```

Обновите SDK именно в Python вашего бота и перезапустите его в удобное время,
чтобы использовать новые явные события. Существующие данные сохраняются.
Windows setup создаёт ярлыки, portable ZIP нужно распаковать целиком;
Linux AppImage и Python wheel/sdist приложены отдельно.

---

Custom event analytics with `monitor.track_action()` and sync/async function
decorators, timelines, outcomes, duration and timestamped history. Russian-first
GitHub documentation, bilingual PyPI description and copyable AI integration
instructions in the repository, wizard and dashboard. Regular Python and existing
venvs are both supported. No new runtime dependencies. Upgrade the SDK in the bot’s
own interpreter and restart at a suitable time; existing history remains compatible.

Early preview for one trusted owner. See README for scope and process-control limits.
