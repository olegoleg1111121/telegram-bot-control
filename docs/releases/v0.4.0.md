# Telegram Bot Control v0.4.0

- Optional authenticated browser dashboard with configurable host and port.
- Desktop web controls and independent `tgbots web` CLI for headless hosts.
- Browser sessions, origin checks, login throttling and a responsive phone layout.
- Required environment checks are empty by default; bots can load their own .env.
- Base Python install requires psutil only; aiogram integration is an optional extra.
- Local Inter Variable font for Latin/Cyrillic, including its license.
- Frontend-only React/icon dependencies are excluded from Electron runtime packaging;
  Chromium locale files are limited to English and Russian.

Default SDK/desktop transport remains SQLite and stdio/SSH with no HTTP listener.
Python wheels include web assets. Desktop builds remain unsigned. Android/Termux
instructions require validation on the intended device; Windows HTTP and UI checks
do not constitute an Android test.
