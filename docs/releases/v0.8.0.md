# Telegram Bot Control 0.8.0

Desktop-приложение теперь получает обновления из официальных GitHub Releases.
Проверка при запуске и каждые 6 часов, фоновая загрузка, прогресс и кнопка
**Установить и перезапустить**. Боты продолжают работать; настройки и история сохраняются.

В настройках можно отключить фоновую загрузку и получение предварительных версий,
проверить новую сборку вручную. Ошибки ручной проверки показываются в отдельном окне.
Поддерживаются установленное Windows-приложение и Linux AppImage; ZIP обновляется вручную.

**Переход с 0.7.0 и старше:** один раз скачайте и установите новый Windows `.exe`.
Автообновление будет работать для последующих версий. Для Linux используйте AppImage.
Python SDK и браузерная панель обновляются отдельно:

```sh
python -m pip install --upgrade telegram-bot-control
```

[Подробнее / Details](https://github.com/olegoleg1111121/telegram-bot-control/blob/main/docs/updates.md).
Windows-установщик пока не подписан Authenticode; загрузки проверяются по SHA-512.

---

Desktop updates now come from GitHub Releases: startup/six-hour checks, background
downloads, progress and **Install and restart**. Bot processes and history are preserved.
RU/EN settings control automatic downloads and prereleases. Windows NSIS and Linux
AppImage are supported. Versions 0.7.0 and older need one manual upgrade; extracted
ZIP builds update manually. The Python package/browser dashboard is updated with pip.
