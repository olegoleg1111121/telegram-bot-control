# Telegram Bot Control 0.7.0

Установка и запуск теперь как у обычного Python-приложения:

```sh
python -m pip install --upgrade telegram-bot-control
tgbots
```

Панель открывается в браузере, локальный вход выполняется автоматически.
Python и стандартная папка выбираются без ручной настройки. Если команда не найдена,
используйте `python -m telegram_bot_control`. Терминал остаётся открытым; Ctrl+C
останавливает панель, сохраняя работу ботов.

В дополнительном desktop-приложении появился поиск установленных Python, проверка
библиотеки, выбор файлов/папок и окно ошибок с конкретной причиной. Перепутанные
поля Python и статистики можно исправить кнопкой. Запуск Electron: `tgbots desktop`.
` tgbots open ` теперь открывает браузерную панель. `tgbots web` сохраняет режим сервера.

Автовход использует одноразовую короткую ссылку только для локального браузера;
обычная авторизация для доступа из сети сохранена. Добавлены проверки Python 3.14.

---

Bare `tgbots` now opens the bundled browser UI with one-time local sign-in, using
its own Python and default data directory. The optional desktop app discovers
Python runtimes, checks SDK readiness and shows actionable modal errors. Existing
bot integrations and history remain compatible. `tgbots open` opens the browser;
use `tgbots desktop` for Electron, or `tgbots web` for a headless server.
