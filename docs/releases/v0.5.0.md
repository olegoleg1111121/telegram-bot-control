# Telegram Bot Control 0.5.0

- Opt-in copying of existing Python logging and Loguru records, preserving existing
  handlers and sinks. Search, levels, traceback and bounded retained history per bot.
- CPU, RSS and thread history from each bot's own process, with per-session charts
  and a warning when multiple bots share a process.
- Opt-in bounded on-failure restart policy in the detached launcher, with exponential
  delay, stable-runtime reset, manual-stop cancellation and visible retry state.
- Read-only existing-project discovery and guided SDK integration; explicit launch
  registration, empty optional env-file field and no execution during discovery.
- Same capabilities in desktop and authenticated web interfaces, Russian/English.

Existing bots must update their SDK and restart to collect resources or attach log
adapters. Additive mailbox tables preserve prior statistics and error history.
This release does not import old log files or install an OS boot service.

Validation details are in [validation.md](../validation.md). Windows was exercised
locally; Linux CI, real SSH and a physical Termux device require separate runs.
