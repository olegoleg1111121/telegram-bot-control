# Telegram Bot Control 0.6.1

Простая установка: в README и PyPI теперь готовый Windows-установщик и запуск
браузерной панели двумя командами. Пользовательские инструкции используют обычный
Python; команды и пути из рабочей копии разработчика убраны.

Node.js и pnpm вынесены в отдельную инструкцию для изменения исходников,
с официальными ссылками и командой установки pnpm. Обновлены обучение и промпт для ИИ.
Команда open находит приложение в стандартных папках Windows, а при отсутствии
предлагает готовый установщик и браузерный режим.

```sh
python -m pip install --upgrade telegram-bot-control
python -m telegram_bot_control web --port 8765
```

Откройте http://127.0.0.1:8765 и введите ключ из терминала.
Для отдельного окна Windows скачайте приложенный установщик `.exe`.

---

Installation now starts with ready-made Windows downloads or a two-command browser
setup using regular Python. Source builds and Node.js/pnpm installation are documented
separately. Windows desktop discovery and missing-application guidance are improved.
Existing bot data and integrations remain compatible.
