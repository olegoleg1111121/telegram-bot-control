# Telegram Bot Control 0.5.1

Startup errors now retain redacted stdout/stderr from both preparation commands and
the bot command, including exceptions raised before the monitoring SDK connects.
The latest launch card opens a command-output block automatically on failure and
allows copying the details. Older launches without captured output explain that a
new attempt is required.

Capture runs in bounded background readers, keeps the latest 32,768 characters per
launch, omits excessively long lines and retains output for the latest 50 launches
plus active launches. Environment secrets are masked before persistence. Python
children use unbuffered UTF-8 output. No new dependency or listening port is added.

An optional env-file remains empty by default: a bot that loads its own configuration
does not need it. A token set only in an earlier terminal is not automatically
inherited by an application opened later through a desktop shortcut. In that case,
configure the bot's own loader or explicitly select its private env-file.
