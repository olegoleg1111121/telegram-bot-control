# Telegram Bot Control v0.3.1

Desktop usability update to the portfolio preview.

- Closing the window hides it in the system tray; tray actions restore it or exit.
- Launching the application again restores the existing instance.
- A five-step Russian/English first-run guide includes a real connection check,
  aiogram integration snippets, bot registration checks and process-control guidance.
- Guide completion and language persist; the guide can be reopened from the sidebar
  or tray and supports keyboard navigation and Escape.
- The Windows installer creates Desktop and Start Menu shortcuts on install/update.
  A helper creates a shortcut to the local unpacked build.
- Explicit `tgbots open --data-dir` opens the selected local directory instead of
  reusing an unrelated saved connection.

Python remains a separate installation. Desktop binaries are unsigned. Independently
running bots keep working when the window is hidden or the application exits.
Linux tray behavior depends on the desktop environment and needs target validation.

See [first-run instructions](../getting-started.ru.md) and [validation](../validation.md).
