# Release v0.3.0

First portfolio preview of Telegram Bot Control.

## Included

- aiogram SDK, persistent telemetry, distinct-user analytics and grouped errors.
- Electron desktop in Russian and English.
- Start, graceful stop and restart with explicit launch profiles.
- Arguments, working directories, preparation and environment-file support.
- Offline examples, process tests and real Electron smoke scenarios.
- MIT license, original app icon, synthetic screenshots and release automation.

## Assets

- `telegram_bot_control-0.3.0-py3-none-any.whl`: install into Python environments.
- `telegram_bot_control-0.3.0.tar.gz`: Python source distribution.
- Full source archive: Python, desktop, examples, tests and documentation.
- Windows setup executable and portable folder archive.
- Linux AppImage when built by the tag workflow.
- `SHA256SUMS.txt`: verify downloaded asset hashes.

Python 3.11+ is required separately. The Windows binaries are unsigned.
Local development builds do not automatically install or publish themselves.

## Validation

Locally exercised on Windows: SDK tests, complex process scenarios, Node bridge tests,
TypeScript/build, lint/format and real Electron controls. A live aiogram bot was
registered and restarted with history preserved. Synthetic data is used for screenshots.

Linux CI and artifact builds are configured and must pass on GitHub before the
owner publishes the draft. No hosted CI result is claimed by the offline package.

## Known limits

One owner/server; separate processes per independently managed bot; no systemd or
Windows-service integration; Python installed separately; queued telemetry may be
lost on abrupt shutdown or storage failure. See SECURITY.md and the launch reference.
