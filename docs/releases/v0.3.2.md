# Telegram Bot Control v0.3.2

- Centers the onboarding language arrow independently of native Windows select styling.
- Adds a visible Connect a bot action that opens the integration step directly.
- Shows the current data directory on an empty dashboard and provides a shortcut
  to connection settings for previously registered bots.
- Clarifies that a successful Python connection check does not install the SDK
  into a bot automatically.

Existing bot history stays in its configured data directory. Select that same
directory in the desktop connection settings to display it.

Python remains separate from the unsigned desktop preview. Linux and hosted CI
validation remain pending.
