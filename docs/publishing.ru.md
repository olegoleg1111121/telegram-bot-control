# Как выложить проект в GitHub

Для установки через pip из PyPI подготовлен отдельный workflow с Trusted Publishing.
[Поля одноразовой настройки и команды установки](pypi.ru.md).

Локальная подготовка и сборка не требуют входа в GitHub. Авторство принадлежит
владельцу проекта; выдуманные Git-имя и email не используются.

1. Для публикации сценарием установите [GitHub CLI](https://github.com/cli/cli#installation)
   и Git. Можно использовать Git из [GitHub Desktop](https://desktop.github.com/download/).
2. Когда сможете войти, выполните `gh auth login --web`.
3. Из корня проекта выполните `.\scripts\publish_github.ps1 -Publish`.

Сценарий возьмёт ваше имя и noreply-email из вошедшего аккаунта, сделает коммит,
создаст публичный `telegram-bot-control`, загрузит `main` и тег `v0.5.1`. Actions
подготовит черновик prerelease. Проверьте сборки и артефакты перед его публикацией.

Без `-Publish` сценарий только показывает порядок действий и ничего не загружает.

Через GitHub Desktop: File → Add local repository → выберите этот проект. После
входа настройте своё Git-имя, сделайте коммит и нажмите Publish repository.

Подготовлены README на двух языках, демонстрационные скриншоты, MIT-лицензия,
changelog, инструкции, CI и сборка релиза. Набор `release/v0.5.1/` содержит исходники,
Python-пакет, установщик, portable ZIP и SHA256. Рабочие базы и секреты исключены.

[Полная инструкция сборки](releasing.md). Установщик приложения не подписан,
Python нужен отдельно. До первой загрузки результаты GitHub Actions и сборка Linux
не заявляются как выполненные.
